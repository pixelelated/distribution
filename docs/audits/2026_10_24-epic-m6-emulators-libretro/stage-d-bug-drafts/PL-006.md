Title: Bug: RetroArch's recipe skips `retroarch32` silently when the ARM root's install directory is not exactly one

Found by the M6 T3 lane (#650), F-11, punch item PL-006. Medium, latent.

## Code trace

- **How it was found:** reading `projects/ROCKNIX/packages/emulators/libretro/retroarch/package.mk` whole.
- **The defect at its source:** lines 106 to 114 install `/usr/bin/retroarch32` on aarch64 only `if [ -f ${ROOT}/build.${DISTRONAME}-${DEVICE}.arm/install_pkg/retroarch-*/usr/bin/retroarch ]`. With no ARM root that test is false, and with two `retroarch-<pin>` install directories (a pin bump in a warm root) it errors with `too many arguments`. Either way the build continues with no 32-bit RetroArch and no message.
- **What it costs:** every 32-bit core fails at launch, because `runemu.sh` 268 to 279 starts `retroarch32` for `pcsx_rearmed32`, `gpsp` and `desmume`.
- **Today:** the four live arm roots each hold one `retroarch-bdba046fa6` install directory, and the H700 and SM8550 images carry `usr/bin/retroarch32`. So it is latent.
- **The fix:** on aarch64 with `ENABLE_32BIT=true`, require exactly one match and `exit 1` naming the path otherwise, the shape of the recipe's own `Configure retroarch for ${DEVICE}` guard (129 to 134).
- **Sibling sites hunted:** the other ARM-root copies (`gpsp-lr`, `desmume-lr`, `compat/box86`, `compat/lib32`) are plain `cp -a`. Under `set -e` those fail loudly on no match; two matches would copy both, which is wrong but loud.
- **What reading cannot prove:** how often a warm root keeps two install directories.

Already written: nothing written; a build-time guard.

Can this be done on the VM? **Yes, on the host**: the recipe's `makeinstall_target` in a sandbox, against constructed ARM roots, as the slice's table regeneration runs the recipe.

## Acceptance criteria

- [ ] The sandboxed `makeinstall_target` exits 1 with the path named for an ARM root with no `retroarch-*` install directory and for one with two, and installs `retroarch32` for one with one.
- [ ] `tools/pkgcheck retroarch` exits 0.
