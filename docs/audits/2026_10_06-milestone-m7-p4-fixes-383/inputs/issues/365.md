## What exists today

Not a cross-cutting look. Each defect got its own code trace, blindspot or friction line. The last look across the work was the futro of 2026-10-01, which looked forward, and the last retro was on 2026-09-28. Since 2026-09-30 the cloud epic (#354) has taken 17 cloud decisions (D-CLOUD-156 to 172) and six kept cuts in nine hours (runs 96 to 101, 2026-10-01 15:42 to 2026-10-02 00:57 UTC). Each cut found a new case and was fixed locally, and the next cut found the knock-on:

- run 99: a fresh device beside an earlier folder holding the saves needed a join (D-CLOUD-169);
- run 99 also measured the follow check's cost, so the check became a setup step (D-CLOUD-170, run 100);
- run 100's proof found the backup making the stock `/GAMES` while the restore half said there was no folder (D-CLOUD-172, #364, run 101);
- run 101: D-CLOUD-172 broke vm-qa's round-trip suite, which backs up into a freshly reset `/GAMES` (0 of 9 files sent), and the pair test's step 5m, which expected the old behaviour.

**Pattern 1, one question decided in seven places.** "Where are this device's saves, and may this actor make that folder?" is answered separately by:

1. the wizard's seeding and `--settle`;
2. the transfer pages' scan;
3. the boot step;
4. the startup sync's restore half;
5. its backup half;
6. the exit sync;
7. the save rows.

No written model says what each actor does in each combination of the conf's folder and the cloud's contents. The cases are being found one build at a time.

**Pattern 2, the proofs that gate a candidate live outside the tree.** Guest d's proof is a session script copied forward each run. Its defects surfaced one per run:

- case D's remembered picks failed twice, and the first time it was rerun alone instead of fixed;
- the script exited 0 over two FAILs;
- the frame-diff claims were a pixel short;
- the fixtures named the old folders (blindspot 71);
- time-to-play's conf copy failed silently, and was first misdiagnosed as a slow probe (blindspot 64's shape).

**Pattern 3, the loop rewards local patches.** Each cut costs a build plus about 90 minutes of proofs. A found defect becomes a fix, records and a new cut, so the next failure is found before anyone asks what produced the last one.
