# M7.P3: Keep package counters out of overall build progress

Source: https://github.com/pixelelated/distribution/issues/412
Updated: 2026-10-04T06:15:36Z

## Observed defect

During the frozen pixelelated b137d8c373 cold build, the watcher's `progress:` line showed `[130/130]` at 06:00 UTC. That was a completed package's Ninja counter copied into the aggregate log, not overall build progress. The structured pkgbuilder line subsequently showed `[616/642] [DONE] install ...`. `tools/watch-job` currently takes the last generic `[N/M]` match in the main log, so package output can overwrite the reported total.

The watcher remained running, with fresh detailed activity and no terminal result. This is a progress-display defect; no completion or stall-detection failure is claimed. Preserve the active run-owned watcher and frozen b137 checkout.
