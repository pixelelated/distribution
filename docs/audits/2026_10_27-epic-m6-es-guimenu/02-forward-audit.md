## What T31 to T37 inherit

Written, not tested here:

- **The page builders' pattern:** one function per page, built in place; a wizard page is shown by `cloudSetupPresent` as its scope's last statement, its callbacks handing the new page on (§ The transitions); a button bar is rebuilt only at build or posted, never from a button's own callback (`es-code-traps.md`).
- **The rows' store rule:** a row's store is its builder's `storeInSettings` or its save hook's writer; a key is written where its reader reads it (L-09, L-10 are what happens otherwise); a page of `addInputTextConfigRow` rows only needs its own save (L-12).
- **The readers' rule:** a file another process writes is read uncached (`exists(p, false)`), `isRegularFile` included (L-03); an image another page may still hold is asked for by a path that names its session (L-02).
- **The quoting function:** one algorithm, `Utils::String::shellQuote` (L-27).
- **The commands' reader:** `GetShOutputLines`, not `GetShOutput` (L-05).
