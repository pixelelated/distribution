**Where (at `16dbac5211`):** `Window.cpp:1031-1041` (the compares `:1032-1033`; `setHelpPrompts` `:1005-1078`)

**The defect:** `setHelpPrompts` merges a dpad half into an existing prompt with the same action text when `it->first == "up/down" && addPrompts.at(...).first != "left/right"` (and the mirror).
