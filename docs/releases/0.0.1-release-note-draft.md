I'm preparing pixelelated 0.0.1 for handheld players who want cloud saves and offline achievements, with clearer setup and recovery when something goes wrong.

### What's new

- Choose separate cloud folders for saves, settings, and your game library, then check or create them before enabling automatic transfers.
- Cloud Connections lets you add accounts, sign in again, switch the active connection, or remove a connection without deleting files in your cloud.

### What's fixed

- Supported GameCube RVZ files are identified correctly when preparing games for offline achievements.
- Opening the sign-in browser releases unused menu memory, and a failed browser launch offers a retry or a way back.
- The Wi-Fi picker keeps your place during refresh, and Back responds while a scan is still running.
- Pending offline achievements resume sending when connectivity returns during startup.
- An interrupted Steam client installation can be retried while keeping an existing profile.

### What to know

- New cloud setups use `/pixelelated`, while existing sign-ins and selected folders stay unchanged; arrange any existing cloud files yourself.
- Automatic save states depend on the emulator, ordinary game saves are separate, and standalone Flycast uses its own automatic-state settings.

The default SSH password for `root` remains `rocknix` in 0.0.1 unless you've changed it; use SSH only on a network you trust.

pixelelated is my independent fork of ROCKNIX/JELOS, with their credits retained; it isn't an official or endorsed ROCKNIX release. The [distribution repository](https://github.com/pixelelated/distribution), [distribution licence terms](https://github.com/pixelelated/distribution/blob/077197e6cd3ea31f33b28aaf3882a694b3423b53/LICENSE.md), and [branding terms](https://github.com/pixelelated/distribution/blob/077197e6cd3ea31f33b28aaf3882a694b3423b53/TRADEMARK.md) describe the project and its permissions.
