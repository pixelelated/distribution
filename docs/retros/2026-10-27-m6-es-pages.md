## Instruction recommendations

Proposals for the coordinator. No rule file was edited by this lane.

1. **A brief's cherry-pick is checked when the brief is written.** `git format-patch -1 <c> | git apply --check` on the target, or `git log <base>..<c> -- <files>`, shows a commit that does not stand alone. It is seconds when the brief is written and a paused stream when the lane meets it.
2. **A count in a post is a tool's line.** Outcome counts come from `grep | uniq -c` over the table, and hashes from `git rev-parse`, as test totals already come from the build script. The S7 summary and the hand-back's 23 are this recommendation's cases.
3. **A sanitizer harness flushes each verdict line.** A leak or race report ends the process through the sanitizer's exit, and buffered stdout is lost; `std::endl` on every case line keeps the before readable.
