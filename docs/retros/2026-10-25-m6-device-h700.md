## What we discovered

- **Every pin in the slice is current with upstream's.** The configuration differs from upstream's copy by the fork's six lines and four upstream commits.
- **atf's H700 branch had no checksum,** fixed twice in incompatible ways: T5's E6 with the old URL, upstream with a new URL. The merge must not mix them.
- **A fresh H700 card names `/dtb.img` and never writes it;** only the updater does (#44).
- **Every H700 image boots with `systemd.debug_shell=ttyS0`,** upstream's choice on seven devices; now the maintainer's question on #346.

## Adjustments, Instruction-Recommendations mode

These are proposals for the coordinator.

1. **Briefs and acceptance scripts:** a history count uses `--since='YYYY-MM-DDT00:00:00Z'`, never a bare date.
2. **`device-builds.md`'s device table:** separate the aarch64 flags, the arm flags and the observed hardware capability (#1094).
3. **For device-script streams:** run the script under the image's interpreter (bash) against fixture paths in `bwrap`, with a success case and the unchanged selection paths as controls.
