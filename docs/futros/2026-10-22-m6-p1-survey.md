## 4. What could we be missing?

**Agent-execution simulation:**

> Archetype simulated: this executor, three hours from now, mid pass 3, after
> a context compaction, holding only the tracking file and the brief.

- **Step 1 (run the 26 plans):** `config/options` writes
  `build.pixelelated-<DEVICE>.<ARCH>/` with two package-cache files into
  whatever directory it runs from. The probe did exactly that (196 K, found by
  diffing `git status --porcelain --ignored` before and after; removed). Run 26
  times it scatters 26 build-looking directories through the lane's worktree,
  which `tools/fork-worktree` would then read as build output.
  **Plan change:** the tool sets `BUILD_DIR` (honoured by `config/path` line 11)
  to a temporary directory it owns and removes, and fails if the worktree's
  ignored set changes across the run. Friction line written.
- **Step 1 (`unassigned: 0`):** an `areas.json` with a catch-all glob makes
  `unassigned` 0 forever, and a path matched by two areas' globs is counted
  twice in every total.
  **Plan change:** the tool prints and fails on `ambiguous: N` as well as
  `unassigned: N`, rejects a bare `**` glob, and a fixture proves both counters
  can go non-zero.
- **Step 1 (reachability):** the naive rule labels every tool, script and
  record `unreached`, and the dead-end set swells to 125,000 paths of `docs/`.
  **Plan change:** reachability has three values for package and device paths
  (`reachable_by`, `buildable_by`/`unshipped`, `unreached`) and a fourth,
  `n/a`, for paths no image plan can contain (build engine, host tooling,
  doctrine, records), so `n/a` is never read as dead.
- **Step 1 (an override that sources the generic recipe):** 47 files under
  `projects/` do `. ${ROOT}/packages/.../package.mk`
  (`grep -rlE '^\s*\. +"?\$\{?ROOT\}?/packages/.*package\.mk' projects | wc -l`;
  `device-builds.md` § After rebasing said 53 on an older tree). Resolution then says the generic directory is not the
  package's, and the generic recipe, which actually runs, would read as
  unreached.
  **Plan change:** a generic `package.mk` sourced by a reached override is
  reached with it, found by grepping the overrides for `packages/<path>/package.mk`.
- **Step 3 (scoring after compaction):** a score copied from a summary instead
  of re-run (blindspot 30, a resumed session built on its own summary).
  **Plan change:** every lens score in the tracking file sits beside the
  command that produced it, so a resumed session re-runs it instead of
  trusting it.

**Pre-mortem:** a month out, slice T1 is dispatched and its executor finds it
is 40,000 lines, because the launch path reaches through `runemu.sh` into every
emulator wrapper. The post-mortem says the slice was cut from directory names,
not edges. Guard: pass 4 records the call edges (who calls `runemu.sh`, who
sources `001-functions`) and the first three slices are sized from the
inventory's line counts after those edges are drawn, not before.

**Blindspot check:** 1 (assumed-undone: is any of this already built? `git log

brief's commits, `0bfd387f7b` and `43ead8ac45`, and `ls docs/reviews/` shows
