**Assumptions the plan makes that the research tested:**

- *"989 fork-own lines"* (the order's `why`, #658's body) **does not
  reproduce**: GENERIC_X64's fork-own rows sum to 1,217 lines over 8 paths,

- *"its fork-written kernel configuration read as a diff against its base"*
  assumes a base. **There is none in the tree**: the file's header names
  `Linux/x86 6.15.6` while the override recipe builds **7.1.2** for
  `RK3326|AMD64|GENERIC_X64` (`projects/ROCKNIX/packages/linux/package.mk:36-40`)
  and runs `listnewconfig` then `yes "" | kernel_make oldconfig`, so every
  option new between 6.15 and 7.1 takes its default at build time and the
  committed file is not the configuration the kernel is built from. The
  measured candidates: AMD64's conf (12,445 lines, 7.1.2): 7,671 removed /
  2,980 added; LibreELEC's `projects/Generic/linux/linux.x86_64.conf`
