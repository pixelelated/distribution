This extractor is a bounded documentary-input reader, not a link checker or a Markdown/shell interpreter.

It reads only the ten constants in ENTRYPOINTS at d707c82ab8c48b674acc1f95a9571f0cb24d226a. The generated work-log INDEX contributes Markdown destinations and heading structure only. No target blob body is read, even when its metadata says it exists. Entry bytes remain in memory; this packet contains extracted route metadata rather than source copies.

Supported candidate syntax:

- Single-line inline Markdown links/images with a simple label. Destination parsing handles backslash escapes for finding the end, balanced destination parentheses, angle-wrapped destinations and optional title separation. Original destination spelling is retained. Markdown destinations resolve relative to their referring file. Single-line reference definitions and HTTP/mail autolinks are recognized; reference-use expansion and multiline/nested-label CommonMark are not implemented.
- Backtick code spans and slash/file-extension tokens in prose or fenced examples. Recognized extensions are md/json/jsonl/tsv/txt/csv/yml/yaml/py/sh/mk/conf. Shell variables, substitutions, quoting and commands are never evaluated. Explicit repository prefixes are rooted at the repository. Bare rule names listed by the named AGENTS entrypoint have an explicitly labelled canonical-rule context. The eleven local review filenames actually named by docs/reviews/README have a separately labelled local-review context. These contextual resolutions are distinguishable from Markdown-link destinations.
- Literal path :N, :N-M and :N:M suffixes and #anchors are separated and retained. They are not validated. Percent encoding and escaped path characters are not decoded. Empty/same-file fragments have separate handling; the observed corpus has no actual link anchors after slash-separated issue/prose tokens are separated.
- Dynamic/glob/template tokens, fenced audit layouts, absolute/host/guest paths, repository names, branch names, slash-separated prose, and unresolved relative shorthand are separate categories. No wildcard expansion, inferred QA base, historical-ref substitution, URI fetch or recursive link traversal occurs. A coordinator shorthand such as t43-final/ does not authorize a search for a matching directory elsewhere.

For every resolved literal target, nonrecursive git ls-tree -z -l at the pinned commit returns mode/type/OID/blob size or missing. An explicitly named directory remains a single tree entry. cat-file --batch-check obtains only that tree object's serialization size; it is not a descendant content-size sum. Symlink contents and targets are not read or followed. No missing target is labelled stale or broken: it may be historical, generative, conditional or contextual. In particular, the review README describes drift.md as a tool's output, and the instruction-file document describes .github/instructions as retired.

Credentials are excluded before output: both credential-labelled path tokens and all tokens on lines explicitly mentioning credentials/secrets are suppressed. Only an occurrence count and a digest over suppressed metadata survive. No credential target metadata is queried. No sensitive spelling is written in the suppression result. This is a conservative literal redaction rule, not a claim to classify every possible secret-bearing filename.

The finite route table enumerates syntax occurrences, not unique reading obligations. Every row carries its source file/line/column, exact spelling, syntax/context, normalization basis, path/anchor/suffix where resolvable, and classification. target-metadata.json joins by resolved_path; entrypoints.json separately binds all ten source identities. Repeated references remain repeated; grouping deduplicates exact target paths. Logical blob-byte totals count each distinct target path once and do not mean bytes read or physical disk use. Generated producer/update commands remain quoted examples, not invocations made by this reader.

The extractor may conservatively include nonpath slash tokens and basename context. Those stay outside the literal records route table. It cannot determine intention, currency, acceptance, correctness of an anchor, whether a record misleads a reader, or the final T46 reading floor. Root owns those judgments and the brief. This support adds no source cutoff, integration claim, selector recut, audit or execution authority.
