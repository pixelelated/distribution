It is not an assembled firmware candidate or a public ROCKNIX upgrade rehearsal. No physical device or personal cloud was used. CF10 remains pending for the release coordinator; its separate host configuration controls do not establish firmware adoption.

The rejected frames preserve two defects found and fixed during this run:

- The original creation timeout put children in another process group, delaying cancellation. Removing that UI-only wrapper restored transfer-group ownership. [The successful control](receipts/final-cancel-proof.json) completed in 4.20 seconds including frame settlement, with the endpoint still paused, no remaining creation children, and unchanged inventories before/after decline, cancellation, and endpoint resumption. Explicit creation has backend per-call bounds and manual cancellation; no 90-second whole-job deadline is claimed.
- The legacy line reader dropped JSON chunks exceeding 1,023 bytes. The capped byte reader preserves full records, refuses oversized/truncated data, and passed the longer-response regression and final populated French/large-panel proof. The backend also corrected flat selected-root ROM files from an ambiguous empty finding to a misplaced finding, without guessing a system or moving files.
