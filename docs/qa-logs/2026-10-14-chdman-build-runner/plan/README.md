## Dependencies and source costs

Dolphin's [tool target](https://github.com/dolphin-emu/dolphin/blob/6094cfcf7b8fba733b3116fdf3414d51c1c0e4a4/Source/Core/DolphinTool/CMakeLists.txt)
links `discio` and `uicommon`, which both pull `core`; core pulls audio,
input, and video libraries. The minimal **unmodified upstream target** is thus
larger than a stand-alone RVZ codec. The source tree has 970 core `.cpp` files
before feature selection; that is an inventory, not a compiled-unit count.
Avoiding the core graph would require a separately reviewed source reduction.
This proposal keeps the real target and bounds the build instead.

proposed. The distro's separate crosscompile patch is unnecessary for this x86_64 plan:

One retained-input gap is concrete: this toolchain has no **libstdc++.a**.

whole-file hashes before and after application. The static libgcc/libgcc_eh archives and shared
`libstdc++.so.6.0.34` are present and hashed. The patch is **UNAPPLIED** and may
only be applied to the future private export. It preserves the exact chdman,
CHD, and codec sources. The build stage refuses a different post-patch file.
Without this adjustment, an additional exact-target static libstdc++ archive
would be required. After adjustment, qualify the shared C++ runtime with the
produced ELF like the other loader dependencies.
